## 内容安全规则

1. `pending` 字段的 `value` 必须为 `null`。
2. 项目存在不等于素材可以公开，媒体必须单独确认授权。
3. 数字必须同时有来源、统计口径和观察窗口。
4. 联系方式与简历缺失时，入口隐藏或使用页面内提示。
5. 更新后必须运行 lint、构建，并在桌面端和移动端检查实际页面。
